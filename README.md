# ClassQuiz: онлайн-тесты для преподавателя

Веб-приложение для частного преподавателя: конструктор тестов, автоматическая проверка, личные кабинеты учеников и таблица результатов с выгрузкой в Excel. Рассчитано на одного преподавателя и до 50 учеников, интерфейс адаптирован под телефон.

## Возможности

**Для преподавателя**
- Конструктор тестов с пятью типами вопросов: один ответ, несколько ответов, ввод слова, ввод числа, соотнесение
- Комментарий преподавателя к каждому вопросу
- Предупреждение в админке, если вопрос заполнен неправильно (например, не отмечен правильный ответ)
- Группы учеников и назначение теста группе со сроком сдачи
- Таблица результатов «ученик × тест» с фильтром по группе: сданные работы, опоздания, долги
- Выгрузка результатов в Excel (сводная таблица и список всех попыток)
- Ежедневное резервное копирование базы данных

**Для ученика**
- Вход по логину и паролю
- Личный кабинет: список заданий, сроки, задолженности, баллы, средний результат
- После сдачи: правильные ответы и комментарий преподавателя к каждому заданию
- Удобная работа с телефона

## Как считаются баллы

| Тип вопроса | Правило |
|---|---|
| Один ответ | Верно: все баллы, неверно: 0 |
| Несколько ответов | Нужно выбрать ровно правильный набор: все баллы или 0 |
| Ввод слова | Совпадение с любым из допустимых вариантов. Регистр, лишние пробелы и «ё/е» не учитываются |
| Ввод числа | Совпадение с любым из допустимых. `3,5` и `3.5` считаются одинаково |
| Соотнесение | Частичный балл: баллы делятся по числу верно подобранных пар |

Каждое задание сдаётся один раз. Если срок прошёл, тест всё равно можно сдать: он будет отмечен как сданный с опозданием. Пока тест не сдан, а срок вышел, он считается долгом.

## Технологии

- Python, Django (встроенные авторизация, админка, ORM)
- SQLite для разработки, PostgreSQL для сервера
- Bootstrap 5 (адаптивная вёрстка)
- openpyxl (выгрузка в Excel)

## Запуск у себя на компьютере

```bash
git clone <адрес репозитория>
cd classquiz

python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser     # аккаунт преподавателя
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ и войдите под созданным аккаунтом.

### Демо-данные

Чтобы сразу увидеть сайт с заполненными данными (преподаватель, три ученика, два теста, сданные работы и долги):

```bash
python manage.py seed_demo
```

Логины: `teacher`, `ivan`, `maria`, `oleg`. Пароль у всех `demo12345` (его можно задать флагом `--password`).
Команду используйте только для знакомства с сайтом, не на рабочей базе.

### Автотесты

```bash
python manage.py test quiz
```

Тесты проверяют вход и права доступа, подсчёт баллов для всех типов вопросов, сроки и долги, таблицу результатов, выгрузку в Excel и админку.

## Как пользоваться

1. Войдите в **Админку** (кнопка в верхнем меню).
2. **Тесты**: создайте тест. **Вопросы**: добавьте вопросы и заполните нужный блок (варианты ответа, допустимые ответы или пары).
3. **Пользователи**: создайте учеников (логин и пароль). Галочку «Статус персонала» оставляйте выключенной.
4. **Группы учеников**: создайте группу и добавьте в неё учеников.
5. **Назначения тестов**: выберите тест, группу и срок сдачи.
6. Ученики входят по своим логинам и видят задания в кабинете. Результаты смотрите на странице **Результаты** и скачивайте в Excel.

## Запуск на сервере

Секреты и пароли хранятся вне кода, в файле `.env` (образец: `.env.example`). Для сервера поддерживается PostgreSQL,
пошаговая инструкция (nginx, gunicorn, HTTPS, расписание бэкапов) лежит в [DEPLOY.md](DEPLOY.md).

## Резервное копирование

Команда делает целостную копию базы (SQLite или PostgreSQL), сжимает её и хранит последние 30 штук в папке `backups/`:

```bash
python manage.py backup_db
python manage.py backup_db --keep 60    # хранить 60 копий
```

Чтобы копии делались ежедневно, добавьте команду в расписание.

- **Linux (cron)**, каждый день в 3:00:
  ```
  0 3 * * * cd /путь/к/classquiz && venv/bin/python manage.py backup_db
  ```
- **Windows (Планировщик заданий)**: действие «Запуск программы», программа `venv\Scripts\python.exe`, аргументы `manage.py backup_db`, рабочая папка — папка проекта, триггер — ежедневно.

Для надёжности периодически копируйте папку `backups/` в другое место (облако, внешний диск).

## Структура проекта

```
config/             настройки Django и корневые адреса
quiz/
  models.py         таблицы: тесты, вопросы, группы, назначения, попытки
  checking.py       проверка ответов и подсчёт баллов
  services.py       сборка таблицы результатов
  exports.py        выгрузка в Excel
  views.py          страницы ученика и преподавателя
  admin.py          админка (конструктор тестов)
  management/commands/backup_db.py   резервное копирование
  management/commands/seed_demo.py   демонстрационные данные
  tests.py          автотесты
  templates/        HTML-шаблоны
```
